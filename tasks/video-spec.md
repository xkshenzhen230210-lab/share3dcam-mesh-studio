# 1.3.0 相机关键帧视频

在现有模型工作台增加“视频 / Video”页。用户调整模型视角，记录相机关键帧，设置时间，播放或拖动预览，然后导出视频。维持中英双语和 SHARE3DCAM 品牌。

- 相机记录：eye、center、up、垂直 FOV；首帧 0 秒，至少两帧，时间严格递增，最长 1800 秒。
- 位置、观察距离和平滑时间插值；相机方向用四元数插值，避免相对视角穿越目标导致退化。
- 16:9 预览构图；输出 1920×1080 / 3840×2160，24 / 30 / 60 fps，H.264 MP4。
- 相机动画可保存为 JSON 并重新载入。切换模型时清除当前关键帧。
- 视频使用原始贴图和完整细节几何，保持当前剪切盒范围，不显示线框和剪切盒边线。非 OSGB 源模型经独立转换进程准备原精度渲染数据。
- 渲染是独立原生进程逐帧离屏绘制，不录制桌面；FFmpeg 编码。输出帧数由时长和帧率确定，首末相机姿态准确包含。
- 渲染、编码、自动完整解码检查均成功后才发布最终 MP4。支持取消；禁止静默覆盖已有文件；失败保留有用错误说明。
- 本版是模型相机漫游，使用模型已有材质，不引入路径追踪、灯光编辑、音轨或字幕编辑。

完整细节场景须装入内存与显存。首次非 OSGB 导出需准备全精度数据，速度与模型规模有关。H.264 是压缩视频；“原始贴图”不代表视频像素无损。

验证包括相机插值、异常输入、取消、已有文件保护、原生编译、实际藏经阁数据 1080p / 4K 导出和解码、实际 GUI 录帧与播放流程。
