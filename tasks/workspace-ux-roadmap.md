# Mesh Studio 日常工作流规划

| 顺序 | 功能 | 验收方式 |
| --- | --- | --- |
| 1.6.0 | 最近打开、单步打开、盒内聚焦与撤回、两点测距、PNG 截图、重复导出与成果定位 | 用藏经阁走完典型操作，网格、LAS、高斯分别进行持续查看和截图测试 |
| 下一阶段 | 命名视角、剪切范围预设、保存和恢复工作状态 | 关闭后重开同一模型能恢复现场，模型路径变化时明确提示重新定位 |
| 后续 | 面积和高差测量、批量转换队列、导出任务历史 | 已知几何验证单位与精度。批量任务可单独取消、失败后重试并定位成果 |

优先级来自三维工具的公开文档和当前操作路径。常用操作直接放在打开、查看、剪切与成果区域。每次新增工具都验证取消、错误输入、切换模型和重复使用的状态。
