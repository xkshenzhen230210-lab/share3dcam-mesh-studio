# 1.1 模型查看与裁剪

用户授权：加入真实 SHARE3DCAM LOGO、SHARE3DCAM 电商销售中心 / SHARE3DCAM E-commerce Sales Center，中英双语；六类数据都能打开，剪切盒裁剪。

界面：品牌深色顶栏；左侧文件/转换/裁剪参数，右侧内嵌 OSG 视窗。旋转、缩放、平移、归位、顶/前/右视角；六面裁剪盒线框与实时截取；保留盒内三角形、插值 UV/法线后导出 OBJ/OSGB。裁剪不自动封口。输入只读。

数据：GLB / Tiles 使用既有精确解析器；OBJ 原生流式读取；PLY 读取样例的 TextureFile + texcoord + texnumber；STL 二进制按三角形分批读取；OSGB 通过 OSG 读取及最终 LOD 遍历。纹理预览可使用缩小缓存，裁剪导出从原始精度重读。

验收：六种格式实际读取；嵌入视窗真实渲染；剪切盒开关/六面参数/视角操作；相交三角形被准确切开，UV连续；裁剪输出的所有顶点均落在指定盒内；旧转换测试通过；便携版重新打包。
